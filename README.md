# Virtual Piano

A single-page virtual piano built with Vite, React, TypeScript, and Tailwind CSS.
Play it with your mouse, touch, or computer keyboard — sound is synthesized live
with the Web Audio API, no audio files involved.

See `CLAUDE.md` for stack decisions and project conventions.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
